# EX No.4.2. CUT SECTION OF SOLIDS
## DATE:

## AIM: 
To create the solid model from given drawing and section the solid model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
STEP 1: Open a New Design 
Open Autodesk Fusion 360 on the computer and wait until the application is fully loaded. Select 
the Design workspace and click on File → New Design to create a new design file. Make sure 
that the Solid modelling environment is selected before starting the drawing process. 

STEP 2: Start the Sketch Command 
     Click on Create Sketch from the Solid toolbar. The three reference planes (XY, XZ and YZ) will 
appear on the screen. Select the appropriate plane according to the given drawing. The 
selected plane will be used as the base for creating the 2D sketch.

STEP 3: Create the Required Sketch 
    Select the necessary sketching tools from the Sketch toolbar, such as Line, Circle, Arc, 
Rectangle and Polygon, according to the given drawing. Draw the required geometrical 
shapes by selecting the appropriate points on the sketch plane. Enter the necessary dimensions 
using the Sketch Dimension (D) command. Make sure that the sketch matches the given 
drawing.
<img width="301" height="315" alt="Screenshot 2026-11-22 153255" src="https://github.com/user-attachments/assets/d7a7b779-a92a-4c6f-8749-6b88cac7c4eb" />


STEP 4: Modify the Sketch 
      Use the sketch modification tools available in the toolbar to make the necessary changes to the 
sketch. Select commands such as Trim, Extend, Mirror and Move to adjust the geometrical 
shapes. Remove unwanted lines and correct the alignment wherever necessary. Check that the 
sketch is properly completed before proceeding.

STEP 5: Inspect the Sketch Dimensions 
     Select Inspect → Measure from the toolbar to check the dimensions of the sketch. Select the 
required lines, edges or points to measure their lengths and distances. Compare the 
measurements with the given drawing and make the necessary corrections to maintain 
dimensional accuracy. 

STEP 6: Finish the Sketch 
       After completing the sketch and checking all the dimensions, click on Finish Sketch from the 
toolbar. The sketching environment will close, and the completed 2D profile will appear in the 
Design workspace. This profile will be used to create the 3D solid model.
<img width="405" height="136" alt="Screenshot 2026-11-22 153623" src="https://github.com/user-attachments/assets/9d4ecb34-fffd-46d1-aae2-ace9a187d4e7" />


STEP 7: Create the 3D Model Using Extrude 
     Select Solid → Create → Extrude from the toolbar. Click on the required closed sketch profile 
and enter the extrusion distance according to the given drawing. Check the direction and 
preview of the extrusion. Select the appropriate operation, such as New Body or Join, and click 
OK to convert the 2D sketch into a 3D solid model. 

STEP 8: Create the 3D Model Using Revolve 
        Select Create Sketch and draw the required profile for the revolved feature according to the 
given drawing. Make sure that the sketch contains the required closed profile and a suitable axis 
of revolution. Click Finish Sketch to complete the profile. Select Solid → Create → Revolve 
from the toolbar. Choose the required sketch profile and select the axis of revolution. Enter the 
required angle, usually 360 degrees for a complete revolution. Check the preview and click OK 
to create the revolved solid. 

STEP 9: Complete the Solid Model 
       After completing the extrusion and revolution operations, check the overall shape of the 3D 
model. Rotate the model using the ViewCube and observe it from different directions. Make sure 
that all the features match the given drawing before performing the section analysis. 

STEP 10: Create the Section View
      Navigate to Inspect → Section Analysis from the toolbar. Select the required plane or flat face 
to define the cutting plane. Move the cutting plane through the solid model to obtain the required 
sectional view. Adjust the position of the cutting plane using the arrow or offset value. Observe 
the internal structure of the solid model and check whether the required section is clearly visible. 

STEP 11: Adjust the Section Analysis 
       After creating the section view, adjust the cutting plane position to expose the required internal 
features of the solid model. Rotate the model and observe the sectional view from different 
directions. Verify the internal shape and dimensions according to the given drawing. Make 
necessary adjustments to obtain the correct sectional view. 

STEP 12: Complete and Save the Sectioned Model 
     After obtaining the required sectional view, verify the internal features and overall shape of the 
model. Click OK or finish the Section Analysis command to complete the operation. Finally, save 
the completed 3D solid model and section analysis using File → Save for future reference.
